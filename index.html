ABOUT THIS PROJECT

The purpose of this website was created as a final project for Code Tenderloin. It explores the history of aviation, explains how modern aircraft systems operate, and highlights significant aviation accidents along with the safety lessons learned from them. The goal of this project is to help others better understand the technology, engineering, and continuous improvements that make aviation one of the safest forms of transportation.
